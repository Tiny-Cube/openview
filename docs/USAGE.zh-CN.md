# 使用说明与支持边界

通过 Open 或拖入文件载入分子。解析失败时保留当前分子；再次打开文件会取消前一个加载任务。

## 选择、构建与几何

- 选择模式点击原子切换选择，点击空白清除；A 全选，N 全不选。选中2、3、4个原子时分别显示距离、键角、二面角。
- 视口上方 Click/Rectangle/Brush 切换点击、矩形、画笔。按住 C/R/B 临时使用对应工具；松开恢复所选工具。矩形默认替换选择，按住 Ctrl 拖矩形追加；画笔只追加，每次经过同一原子不会反复切换。Shift 拖动仍平移。
- R/B 可在构建模式临时选原子；F＋点击切换整个连接片段，F＋点击不会替换元素。Home 适配视图。矩形在鼠标松开时提交，即使先松开 R；Esc 或焦点移出取消尚未提交的矩形。
- 选择 Element 后进入 Build / replace，Fragment 按元素显示构型。空白点击放置，已有原子点击替换；开放价位可用于拼接。原版111个元素映射与29类模板已接入，未覆盖的元素保留 Atom。
- 构建时按住 C 点击可临时选择连接起点。Bond new atom to selection 默认为关闭；开启后可连接到选中的单个原子。Esc 返回选择。
- 几何编辑默认固定首侧、移动末侧相连基团。环内不能分离的基团需要取消 Move attached group，仅移动末端原子。Cancel 回滚预览，OK 提交为一次可撤销编辑。
- Structure 表的元素和坐标输入用于精确补充。Rebuild bonds 会根据距离重新猜测连接，可能覆盖手工键级，可撤销。

编辑几何会清除旧计算结果、振动和标量场；撤销只恢复几何和连接，不恢复已清除的计算结果。完整力场 Clean、最优二面角搜索和所有复杂环/约束策略尚未实现。

## 文件与保存

GJF/COM 读取首个 Link1 作业，支持数值/变量 Z-matrix、dummy center 和 Units=Bohr。LOG 支持 Gaussian 标准 orientation、SCF Done 与标准谐振动块，并非任意计算程序日志。

FCHK 中坐标按 Bohr 转换为 Å。CHK 原生路径限于已识别64-bit目录布局，读取结构和已验证字段；未知布局需要外部 formchk。原生 CHK 不能宣称完整恢复波函数或振动数据。

XYZ 支持身份/数量一致的多帧。PDB 读取 ATOM/HETATM、MODEL、主要 altLoc 和 CONECT。MOL/SDF 限 MDL V2000，SDF 只读取首条记录。CUBE 支持单标量场、正体素数 Bohr、负体素数 Å及一般线性网格轴。

Ctrl+S 打开 GJF 预览，默认保存显式连接和键级。单帧完整保存后清除未保存提示；取消、失败或多帧仅保存一帧时不冒充完整保存。XYZ 不包含键级。不能写回计算输出 LOG 或二进制 CHK。

## 结果与作业

Results 可播放已解析的振动、显示能量与 IR 曲线。振动播放使用可观察速度，不代表真实物理时间。CUBE 等值面读取已有标量场，不从 FCHK 计算轨道。

Jobs 可调用用户另装的 Gaussian 程序；启动应用前需载入其环境。该模块的真实计算联动仍需在安装 Gaussian 的环境验收，不以模拟任务通过代替真实计算成功。

矩形按当前视图投影中的原子中心选取，不包含原版全部周期副本/隐藏原子策略。F/Alt 片段几何拖动、Fe 构型横向滚动等行为与原版仍有差异。当前至少保留一个原子，不能删除最后一个原子；可通过 New molecule 重新构建。全部原版菜单、快捷键、计算设置、结果和任务管理操作尚未复刻。
