# OpenView 0.4.0

这个版本优先交付日常分子工作台，覆盖打开 → 显示 → 编辑 → 保存，不要求完整复刻原版。

## 可用流程

打开 GJF/COM、Gaussian LOG/OUT、FCHK/FCH 和已识别布局的 CHK；可旋转、缩放、平移，使用球棍、棒状和空间填充样式。选择 2–4 个原子可测量或预览调整键长、键角和二面角。

可添加/删除原子、修改元素及键级，用碳和其他元素的 Fragment 构建或拼接；支持撤销/重做。GJF 保存包含显式连接和键级，可重新读入继续编辑；还可导出 XYZ 和 PNG。

已有轨迹、谐振动和 IR 播放/显示，以及已有 CUBE 网格的等值面。解析、推断连接和等值面运算使用独立工作进程。

## 本版新增

- 点击、矩形、画笔工具及 C/R/B 临时选择。
- F＋点击选择整个连接片段，Home 适配视图，解决 F 快捷键冲突。
- 矩形释放后明确提交，Ctrl 矩形追加，画笔重复经过不反复切换；焦点移出或 Esc 取消未提交矩形。
- File/Edit/View/Help 菜单、内置鼠标键盘说明，统一 Ctrl+Shift+Z 重做入口。

## 运行

解压源码包后，在该目录执行：

```sh
sh install.sh
sh run.sh
```

当前开发工作区也可在外层直接执行 `sh run.sh`，会启动 `openview/` 下的版本。全部 Python 环境由 uv 管理。

## 已验证与边界

本版执行了 79 项单元检查，以及真实 Qt/OpenGL 的交互、选择、非碳 Fragment 和已有功能检查。真实 CHK/FCHK/LOG/GJF 分别完成后台加载、显示、编辑、GJF 往返与撤销；CHK/FCHK 为 50 原子、57 条连接，坐标误差小于 0.000001 Å。输入文件未修改，未随源码包分发。

CHK 限于识别的 64-bit directory 布局；其他布局需要用户另装的 formchk。本版没有把伴随 FCHK 冒充 CHK 解析成功。Gaussian 引擎和真实作业环境仍需用户自行安装及配置。

完整 Clean、全部 SmartSlide、波函数生成轨道、原版所有菜单和 F/Alt 片段几何变形不在本版范围。渲染实测的设备、视口和结果见[验证记录](VALIDATION.zh-CN.md)，不承诺所有输入和设备无卡顿。

分发包仅包含 OpenView 独立源码、测试、文档和自有示例，不包含被逆向的原版软件、密钥、用户计算文件或原始研究捕获。
