# OpenView 0.4.0 可用版本交付

用户要求先交付相对完整、可使用的 Linux 版本，不等待完整复刻。沿用已有 Qt 6/ModernGL 应用，以打开文件、显示分子、直接编辑、保存可重读 GJF 为核心。

在继续大范围逆向、只重新打包 0.3.0、以及补齐实际使用缺口后交付之间，选择最后一种：保留已有解析/构建/几何/播放能力，补齐选择操作和入口可发现性，控制本次范围。高级计算设置、完整 SmartSlide/Clean、全部曲面和原版细节仍留后续。

## 本次行为

- 默认左拖旋转、中键/Shift左拖平移、右键/Ctrl左拖滚转和缩放；旋转不创建原子。
- 选择工具提供点击、矩形、画笔；按住 C/R/B 临时使用点击/矩形/画笔，松开恢复当前工具。矩形在鼠标释放时提交；失去焦点或 Esc 取消未提交区域。画笔追加选择，避免经过同一原子时反复切换。
- F＋点击扩展到连接片段，Home 适配视图；F 不再与适配快捷键冲突。片段几何拖动不在本次范围。
- 菜单共用已有动作，提供文件、编辑、视图和操作帮助；工具栏保留常用入口。所有元素 Fragment 保留当前实现和独立选择记忆。
- 当前加载失败保留旧结构、编辑保留连接/键级、旧结果失效处理、撤销/重做和显式连接 GJF 保存继续作为必要条件。

## 验证与交付

使用 uv 管理解释器、依赖和命令。运行单元及 Qt/OpenGL 检查，对真实 CHK/FCHK/LOG/GJF 执行后台加载、显示、编辑、保存往返和撤销。补充真实鼠标/键盘的矩形、画笔、片段选择和焦点取消检查；测量 Linux 场景下渲染/事件循环，并记录设备和视口，不能承诺所有机器无卡顿。

产物为 0.4.0 wheel 和带 install.sh/run.sh 的源码包，另启动当前桌面版本展示。包内仅独立源码、文档、测试和自有示例；不含原版程序、原包、密钥、用户文件或原始研究捕获。用户计算文件仅本地只读使用。
